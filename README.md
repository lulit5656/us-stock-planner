## 2대 매매 공식 (사용자 확정 · 매수후보 화면)

- **공식 ① 추세 타기 (200일선 돌파·지지)**
  - 현재가 200일선 위(`close >= ma200 * 0.995`)이면서 200일선을 막 깨고 내려가는 음봉이 아님
  - 최근 3거래일 안에 거래량 2배↑(주황 막대, `vol_ratio >= 2.0`)
  - 4개 체크: 200일선 위 / 거래량 2배↑(3일) / 오늘 양봉 / 이탈 아님 → 모두면 `딱 맞음 · 지지 확인`, 거래량·양봉이 빠지면 `거래량 대기`·`양봉 대기`
  - 200일선을 음봉으로 깨고 내려온 종목은 제외하고 **`200일선 이탈 · 관망`** 으로 별도 표시
- **공식 ② 바닥 반등 단타 (200일선 아래)**
  - 현재가 200일선 아래 + RSI(14) ≤ 38 + 볼린저 하단 근접(`%B <= 20` 또는 `close <= bb_lower * 1.03`) + 거래량 2배↑(오늘 또는 최근 3거래일)
  - 4개가 겹치면 **`딱 맞음 · 4개 동시`**, 하나만 빠지면 `거래량 대기` / `RSI 대기` / `볼린저 대기`, 두 개만 맞으면 `근접 2/4`
  - 매도 목표는 각 종목의 **200일선 가격**(예: `반등 시 200일선 $203.35 / 약 274,000원 근처 매도`)
- 데이터 필드: `f1`·`f2`(=state, key, checks, note, sell), `vol_ratio_recent`(최근 3일 배수), `vol_max3`, `vol_spike_3d`, `ma200_break`·`ma200_break_ago`

## 골든존·4중 필터 계산 방식

- **200일선(골든선)**: 일봉 종가 200개 단순평균
- **골든존**: 200일선 ±3% 이내 또는 (RSI 35~45 이면서 200일선 위)
- **4중 교차 필터** (사용자 확정 규칙)
  1. 추세·바닥: 현재가 > 200일선, 20일선 > 60일선
  2. RSI: 35~50 눌림 (50 초과 과열 추격 금지)
  3. 거래량·양봉: 20일 평균의 80% 이상 + 양봉
  4. 손익비: 200일선까지 손절폭 6% 이내 + 52주 고점 대비 10% 이상 여유
- 4개 통과 → "매수 후보", 3개 → 관찰, 2개 이하 → 대기

### 볼린저밴드 · 거래량 · 가짜 상승 경고

- **볼린저밴드**: 20일 단순평균 ± 2표준편차(모집단). 최신 종가 위치를 `상단 돌파 과열` / `하단 근접 반등`(하단 +2% 이내) / `밴드 내`로 표시하고, 밴드 안 상대 위치 `%B`도 저장
- **거래량 배수(vol_ratio)**: 오늘 거래량 ÷ 직전 20일 평균. `2.0배 이상`이면 `vol_spike: true` → 리스트에 🔥 배지, 차트 거래량 막대는 주황색, 홈 카드·거래량 화면에서 모아보기
- **가짜 상승 경고(fake_rally_warn)**: 아래 둘 중 하나면 `true` + 쉬운 설명
  1. 양봉인데 윗꼬리가 몸통보다 길고(`(high-close) > (close-open) × 1.2`) 거래량이 1.5배 이상 → `매물 출회 의심`
  2. 최근 5일 상승인데 CMF(20일) < -0.05 → `자금유입 약함`
- **CMF(20일)**: Σ(((종가-저가)-(고가-종가))/(고가-저가) × 거래량) ÷ Σ거래량, -1~+1
- **RSI(14) 상태 배지**: ≤35 과매도 반등권 / 35~45 눌림목 / ≥70 과열 / 그 외 중립
- **RSI(14) 선 그래프 패널**: 종목 상세 차트의 세 번째 패널(가격·RSI·거래량 시간축 동기화). Wilder 평활 방식으로 일봉·주봉 전 구간을 계산해 `docs/data/hist/{종목}.json` 의 `rsi14` 배열(앞 14개 null)에 저장하고, 70(과열)·30(과매도) 점선 기준선과 현재 수치·상태를 범례에 표시합니다. 툴바 `[RSI]` 버튼으로 끄고 켤 수 있고 기본은 켜짐입니다.

## 자동 갱신 켜기 (한 번만)

이 저장소는 지금 **자동 갱신 워크플로가 빠진 상태**로 배포되었습니다. Pickle 의 GitHub 앱에 `Workflows` 쓰기 권한이 없어 `.github/workflows/update.yml` 푸시가 거절되기 때문입니다.
둘 중 하나면 됩니다.

1. GitHub에서 `us-stock-planner` → **Add file → Create new file** → 파일 이름 `.github/workflows/update.yml`, 내용은 이 저장소의 `scripts/update.workflow.yml` 을 그대로 복사 → Commit. (Actions 탭에서 15분 주기 실행 시작)
2. 또는 GitHub **Settings → Applications → Pickle → Configure → Permissions → Workflows: Read and write** 로 바꿔 주시면 제가 직접 올려둡니다.

## 직접 갱신하기

```bash
python3 scripts/fetch_data.py     # 표준 라이브러리만 사용 (yfinance 불필요)
```

테마·종목을 추가하려면 `scripts/universe.py` 의 `THEMES_US` / `THEMES_KR` / `STOCKS` 를 고치고 다시 실행하면 됩니다.
`docs/index.html` 의 `app.js?v=` / `style.css?v=` 값은 두 파일을 고칠 때 함께 올려 주세요(브라우저가 옛 파일을 계속 쓰는 걸 막습니다).
야후 티커는 미국 `NVDA`, 코스피 `000660.KS`, 코스닥 `045970.KQ` 형식입니다.
