# 📈 글로벌 주식플래너 (미장 · 국장)

폰에서 앱처럼 열어 보는 **테마 대장주 대시보드**입니다.
"오늘 뜨거운 테마 → 대장주·관련주 → 이 회사 뭐 하는 곳인지 → 월가 목표가 → 200일선 골든존 매수 위치"를 한 번에 봅니다.

- 사이트: `https://lulit5656.github.io/us-stock-planner/` (Pages 배포 후)
- 데이터: 야후 파이낸스 공개 API · **약 15분 지연** · 일봉 종가 기준
- 종목: 미국장 58 · 국장 20 (테마 11 + 5)

## 골든존·4중 필터 계산 방식

- **200일선(골든선)**: 일봉 종가 200개 단순평균
- **골든존**: 200일선 ±3% 이내 또는 (RSI 35~45 이면서 200일선 위)
- **4중 교차 필터** (사용자 확정 규칙)
  1. 추세·바닥: 현재가 > 200일선, 20일선 > 60일선
  2. RSI: 35~50 눌림 (50 초과 과열 추격 금지)
  3. 거래량·양봉: 20일 평균의 80% 이상 + 양봉
  4. 손익비: 200일선까지 손절폭 6% 이내 + 52주 고점 대비 10% 이상 여유
- 4개 통과 → "매수 후보", 3개 → 관찰, 2개 이하 → 대기

## 구조

```
docs/                 ← GitHub Pages 루트
  index.html  app.js  style.css  manifest.json  icon.svg
  vendor/lwcharts.js  (Lightweight Charts 4.1.3 로컬 사본)
  data/stocks.json    (지수·테마·종목 요약 + 지표·목표가)
  data/hist/{종목}.json (일봉 2년·주봉 5년, 종목 상세에서 지연 로딩)
scripts/
  universe.py         (테마 구성·한국어 종목명·회사 설명)
  fetch_data.py       (수집·지표 계산·JSON 생성)
.github/workflows/update.yml   (30분마다 자동 갱신)
```

## 직접 갱신하기

```bash
python3 scripts/fetch_data.py     # 표준 라이브러리만 사용 (yfinance 불필요)
```

테마·종목을 추가하려면 `scripts/universe.py` 의 `THEMES_US` / `THEMES_KR` / `STOCKS` 를 고치고 다시 실행하면 됩니다.
야후 티커는 미국 `NVDA`, 코스피 `000660.KS`, 코스닥 `045970.KQ` 형식입니다.

## 한계

- 무료 공개 데이터라 **약 15분 지연**되고, 지표는 일봉 종가 기준이라 장중 흔들림 반영이 늦습니다.
- 애널리스트 목표가는 야후 집계 평균이며 미래 가격을 보장하지 않습니다. 국장 중소형주(코아시아·유니트론텍)처럼 집계가 없으면 "목표가 집계 없음"으로 표시합니다.
- 수급 필터는 기관·외국인 원자료가 아니라 **거래량 비율**로 대신합니다.
- 투자 판단 참고용이며 매수·매도 권유가 아닙니다. 손실 책임은 본인에게 있습니다.
